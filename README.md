FITBUDDY AI- AI FITNESS PLAN GENERATOR USING GEMINI MODELS

About The Project

FitBuddy AI is an AI-powered fitness plan generator that creates personalized 7-day workout plans based on the user's fitness details using Google Gemini Models.
